## 0b. 知识锚可信度（Knowledge-anchor · D1 配套）

| 项 | 内容 |
|---|---|
| **出处** | **Shannon, 1948** · *A Mathematical Theory of Communication* · 信息量 / 熵；科普常用 **surprisal** \(I = -\log p\)（单位 bit 当以 2 为底） |
| **示意边界** | 预期破裂隐喻、可能空间压缩手势、噪声遮挡后仍可见的结构线、计量 vs 意义双栏 —— **教学示意**，**不是** Shannon 原图复绘、**不是**实测语料/信道实验曲线；数字与公式旁必须留「示意」脚注 |
| **易杠点** | 见下表 |
| **免责** | 源片/公开赏析未给出实验级 disclaimer；我们成片保留「示意 / 科普压缩」；禁写成「信息论证明日常 X」 |

### 易杠点（短表 · LOCK）

| # | 易被杠的断言 | 我们的处理 |
|---|---|---|
| 1 | 「惊奇量 = 信息量」把主观惊讶直接等同 Shannon 信息 | 写「可比较的意外程度 / 科普常称 surprisal」；禁「科学上你的惊讶就是 bit」 |
| 2 | 用日常例子推出「这句话含 N bit」精确值 | 只做相对高低；数字标 **示意**；禁伪精确到小数 bit |
| 3 | 「信息 ≠ 意义」被读成「信息论否定语义/人文」 | 保留并列对照；脚注「计量不覆盖语义解释」；禁嘲讽意义研究 |
| 4 | 冗余/噪声段被读成「多说废话就抗干扰」万能法则 | 写成信道直觉示意；禁工程保证口吻 |
| 5 | 公式墙开场 → 评论区「又在炫公式」 | **公式永远在可感知差别之后**（KEEP）；开场只给预期破裂 |

## 1. 一句话（静音能懂的论证骨架 · KEEP · D1）

**预期破裂**（日常可预测 vs 不可预测）→ **把「惊奇」变成可比较的量**（交互小工具逐步压缩可能空间）→ **冗余 / 噪声**（结构在干扰下仍可辨）→ **信息计量 ≠ 语义意义**（并列对照）→ **首尾回调**（开场物件变形归来）。

公式 **永远出现在可感知差别之后**，不当开场墙。

撞车：与 moyou（音乐多巴胺）、circuit-board（PCB 路径）不同理论家；同「预期/信息」话术时仍须新隐喻 + 新 gadget（见 BANNED）。

## 2. KEEP · 语法

### 2.1 色板角色（语义色 · D3 · KEEP）

| 角色 | 用途 | 建议锚 |
|---|---|---|
| **结构蓝** | 坐标、框线、保留区间、信道骨架、未变部分 | `#3A7BD5`–`#5B9FE8` 细线 / 描边（yaml `#4A8FE0`） |
| **惊奇金** | 新信息、难预测落点、事件标记、光标/节点 | `#E8B84A`–`#FFC857` 填充/高亮 |
| **深底** | 近黑海军，少纹理 | `#0A0E16` → `#121826` |
| **ink 白亮** | 底栏叙事 / 主结论句（系列静音硬规则） | `#F2EEE6` / `#FFFFFF`，粗、大 |
| **muted** | 脚注、次级标注 | `#8A90A0` |
| **异色缺失** | 被噪声吃掉 / 遮挡处（非第三语义主色） | 低饱和红或冷灰（yaml `#C86A6A`），慎用 |

全片 **蓝=结构、金=变化/惊奇** 不换角色；换选题只换物件，不换这对语义。  
与近亲一句：`moyou` 琥珀金=预期/DROP；本底座 **金=惊奇落点**、**蓝=保留结构**；脚本锚在 **text↔chart + 底栏 narrative**，非 moyou 左上巨标题床。

### 2.2 字阶系统（yaml / NavXD 组织锚 · D2 · LOCK）

**无本地密帧实测**；下表来自 `style-base.yaml` type 块 + STYLE-BASE / NavXD「大字讲义 + 图注」观察，一律 **约值 @1080**。有本地 dump 后须用 bbox 重校，禁止把约值当原作实测。

| 角色 | 证据锚 | 约字号@1080 | 字重 | 颜色 | 位置 |
|---|---|---|---|---|---|
| **hero / headline** | yaml `type.headline` · 钩子问句 / 金句 | **约 80–96px**（yaml **88**） | 900 | ink 白；金关键词 ≤2 | 上区或图侧主句 |
| **narrative** | yaml `type.narrative` · 底栏讲义 | **约 44–52px**（yaml **48**） | 800 | ink_hi 白亮 | 底栏 band ≈ y **900–1020** |
| **callout / novelty** | yaml `type.novelty` · 惊奇金事件词 | **约 32–40px**（yaml **36**） | 800 | surprise 金 | 图内骑位点 / 高亮词 |
| **chart_label** | yaml `type.chart_label` · 轴/区间标签 | **约 26–32px**（yaml **28**） | 600 | structure 蓝 | 贴轴、贴线 |
| **formula** | yaml `type.formula` · 示意式 | **约 36–44px**（yaml **40**） | 600 | ink | 例后出现；旁注「示意」 |
| **foot / HUD** | yaml `type.footnote` | **约 20–26px**（yaml **22**） | 500 | muted | 角注 / 次级 HUD |

关键词高亮规则：每屏烫金（惊奇）强调 **≤2 处**；蓝只给结构标签，**不抢**底栏 narrative 正文。  
禁止：同级卡片换词当字阶；把底栏做成口播字幕带字号墙。

### 2.3 文字 ↔ 图表 handoff 节奏（D5 前置 · KEEP）

| 拍型 | 谁主讲 |
|---|---|
| A · Text-lead | 钩子问句 / 金句大字；图只作衬底或单标记 |
| B · Chart-lead | 轴 / 区间 / 波形 / 编码条主舞台；字缩成标签与底栏 |
| C · Dual | 左右或上下并列（计量 vs 意义）；两栏角色色分开 |

规则：相邻两拍 **至少换一次主讲权**（A→B 或 B→A）；禁止连续三拍纯字墙或纯图无字。

### 2.4 论证顺序（骨架可复用，例子必须新）

1. 预期与意外（同形动作，不同可预测度）  
2. 把可能空间变成 **可操作的压缩动作**  
3. 概率 / surprisal 直觉 → 再给符号  
4. 冗余与噪声  
5. **信息 ≠ 意义** 并列  
6. 日常回调  

### 2.5 静音文字（系列 + 本底座）

- 底栏默认 **白亮、更大更粗**；角色色（蓝/金）只给标签与高亮词，不抢底栏正文。  
- 一屏一意；钩子问句、数字、对比栏要能截图。  
- 数字 / 公式标「示意」或脚注；不作实测气象/历史数据。

## 3. 道具语法（D6 · KEEP）

| 抽象槽（KEEP 角色） | 做什么 | persist+morph | 禁止 twin |
|---|---|---|---|
| **SurprisalMeter** | 「意外程度」相对量 | 句间不消失；刻度/填充连续 | 诗句信息条孪生 |
| **PossibilityCompressor** | 很多可能 → 更少可能 的手势/机构 | 区间/候选集逐步收窄 | **B2 数轴折半** |
| **StructureWire** | 蓝色细线骨架 | 噪底下仍可辨；线不每句重置 | 同构图蓝轴换标签（B3） |
| **NoveltyMark** | 金色事件/新比特落点 | 落点亮起/叠加入 | 同款金点+蓝轴签名床 |
| **NoiseVeil** | 遮挡/打乱后仍露蓝结构 | 帷幕密度 morph | 同款广播乱码舞台 verbatim |
| **MeasureVsMeaning** | 双栏：可计量 vs 语义 | 两栏状态差可读 | **B5 推荐卡趋同** |
| **CallbackObject** | 片头引入、片尾变形归来 | 同物件变形，非换新图 | **B6 诗句回调** |
| **FormulaAfter** | 例 → 观感差 → 再给符号 | 公式晚于差别 | 公式墙开场 |
| **DualCompareColumns** | C 拍并列 | 栏宽/高亮对打 | 同推荐卡双字串 |

跨拍复用变形；同主道具连续两拍必须有状态变化。  
**允许发明（N≥1 必新）：** 开场惊奇隐喻（禁诗填空）；bits/surprisal 零件（禁 B2）；信息≠意义舞台（禁 B5）；收束回调（禁 B6）。

## 5. 图内展示（INFRAME-SHOW · D5 · KEEP）

权威：`docs/INFRAME-SHOW.md`

| 优先级 | 承载 | 本底座例子 |
|--------|------|------------|
| 1 · 论证本体 | 图内 gadget | PossibilityCompressor、StructureWire、NoveltyMark、NoiseVeil、MeasureVsMeaning、SurprisalMeter |
| 2 · 定向/钩 | hero + 底栏 narrative | 问句/金句；**designed** 白亮底栏（非口播带） |
| 3 · 标签 | chart_label / novelty | 蓝轴注、金事件词骑位点 |
| 4 · 脚注 | foot | 「示意」· Shannon/surprisal 短引 |

规则：
1. **禁止** continuous bottom white **口播字幕带**当唯一讲义；底栏是设计叙事，须与 chart 换权。  
2. densest：**走到哪标到哪**；论证挂在区间收窄 / 金落点 / 帷幕下蓝线 / 双栏状态差。  
3. 主道具 **persist + morph**（反翻页、反整卡 swap）。  
4. 论证拍 ≥**70%** 挂在 gadget 状态变化上。  
5. **Gate 必写：`crop-bottom mute: pass|fail`**  
   - 操作：裁掉底栏 narrative band（约 y≥900）后静音看 densest。  
   - **pass** = 只靠图内蓝/金状态 + 图内标签仍能讲完「可能在收 / 新信息落下 / 噪底有结构 / 计量≠意义」。  
   - **fail** = 离开底栏字就不会 · 或只有字墙无 morph。
