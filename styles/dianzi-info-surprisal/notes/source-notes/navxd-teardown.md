## NavXD “想做类似的” drills (OK as abstract exercises — NOT shot twins)
1. Two same-form examples with different predictability — show the difference first.  
2. One color for remaining possibility, one for new information — keep all film.  
3. Explain a quantity via successive exclusion, then reveal the symbol.  
4. Return to the first example; state what the model does **not** measure.
