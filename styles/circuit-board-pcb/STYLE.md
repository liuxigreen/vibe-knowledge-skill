# circuit-board-pcb · 电路板（Lemo-Opuscar「七毫秒」复刻级底座）

来源：Lemo-Opuscar `styles/circuit-board`（MIT, © 2026 LemoLab）STYLE.md + DEMO.md + demo 源码 + 60s 成片逐秒拆帧（`episodes/earworm-pitch-v2/gate/ref/`）。
取代 v1 的 `circuit-board`（那版是暗金卡片管线套绿色，近黑、稀疏、无相机）。

## 0. 判定：不是 3D
参考片是**正俯视 2D PCB**（STYLE.md 明令"Nothing is drawn in perspective / not a 3D circuit city"）。
深度感全部来自：多层材质叠加 + 加法辉光(双半径) + 上下景深带 + 前景失焦光斑视差 + 暗角 + 胶片颗粒 + 相机跨尺度推拉。
→ 渲染用 Canvas2D 分层合成（headless Chrome），**不用 three.js 透视**；用 three.js 反而违背模板。

## 1. 材质层（自下而上，同一 world→screen 相机）
1. 基材 FR-4 `#05190F`：两倍频玻纤编织纹交叉淡入，任何缩放下纹理尺寸有界。
2. 铺铜 `#1C6A44` + 亮边 `#4AA977`：所有元素都是从铜里**挖出来的间隙**；两遍绘制（rim 原间隙，fill 间隙+1.6px）→ 每条铜边都有倒角亮边；铺铜上有极淡阻焊斑驳。
3. 走线：rim `#4AA977` 外描 + fill `#2B8158` 内描，圆头；两侧露基材沟。只走 0/45/90°，转角斜切。
4. 裸金属：ENIG 金焊盘 `#D9B25B`（上 1/3 高光带，钻孔暗芯 `#06130D`）；过孔=金环暗孔；裸铜只给一个重点件。角上有 fiducial / 安装孔。
5. 丝印 `#F2EEE1`：单线描边、针孔噪点、0.35px 微糊；器件轮廓、位号、极性、符号、标签。
6. 光（唯一饱和色）：加法层，blur≈24px + ≈5px 两遍 + 锐利原层。琥珀 (255,190,84) 白芯 = 主信号；银青 (170,214,226) = 第二种流；红只用于一次故障。
7. 屏幕空间：左上暖主光缓慢漂移、上下景深带（读字时弱）、前景失焦光斑视差、暗角、胶片颗粒；结尾桌面+窗光。

## 2. 排版
- 所有字都是**丝印**，锚在板上，**一笔一笔"绘出"**（plot），镜头拉远时仍在。
- 中文标签在上、英文小一号在下，同线宽。拉丁/数字用路由单线字体（Lemo font.js, MIT）；中文用 Noto Sans SC 细中黑 + 针孔纹 + 左→右绘出遮罩（差距：非手工路由汉字）。
- 板上只印关键词和数字，不印整句；整句走底部字幕：深色半透明底板，中文 40px（Noto Sans SC），安全区内。
- 读字时长 ≥1.5s + 字数/4.5s；标签全程在画内，不进景深带。标题 ≥60px。

## 3. 动画逻辑（光的移动就是讲解）
- 交流/往复：短划线来回摇摆；直流/单向：行进光头 + 余辉 + 流纹；降压：线变细、划线变小；第二流：多条平行流线不同速度。
- 焊盘到达即闪（快闪→稳亮）；器件"导通"时符号内边发光。
- 丝印只能绘出；铜和焊盘从不凭空出现（板是静止的，只有相机动）——新信息靠**光点亮已有的铜**、靠相机走到下一个区域。
- 节奏：时钟晶振 Y1 每拍发一个脉冲；焊盘在强拍上闪；频谱 LED 阵按真实 BGM 频带能量逐帧亮起（峰值保持）。

## 4. 相机语法（正俯视，只允许绕视轴小转）
骑脉冲 / 边骑边升 / 砸焦到焊盘 / 锁定微距读数 / 沿走线甩 / 同符号匹配剪 / 钻过孔进入子板 / 跨嵌套板连续拉远。
被照亮的主体在三分线或居中；周围至少两层细节（背景铜/过孔/走线 + 前景光斑/景深）。

## 5. 节拍与剪辑
- 参考片 12 镜/60s，每镜 ~5s，镜内相机几乎从不静止。我们的 4–5 分钟长片：每句口播一个镜头设计，镜内至少一次相机运动；镜间优先"沿光走过去"而非切。
- 甩/砸焦的落点卡在 BGM 强拍（beatgrid）上。

## 6. 禁止
照片、手写、玻璃 HUD、悬浮面板、透视楼宇、整句上板、per-scene 换底色、无动机的硬切新卡。
