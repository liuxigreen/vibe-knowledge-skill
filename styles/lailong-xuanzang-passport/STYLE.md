## 1. Palette & typography

| Token | Approx | Use |
|---|---|---|
| `bg` | `#1A120C`–`#2B1D13` | 夜褐 / 土褐史剧底 |
| `ink` | `#F5F0E6` | 主叙事句 |
| `robe` | `#C45C2A` | 僧袍橙 |
| `gold` | `#E0B85A` | 路线发光、重点句 |
| `mark_blue` | `#6BA3C9` | **下划线强调**（信佛、数字） |
| `mark_red` | `#C45C4A` | **动作强调**（撕了） |
| `map` | 深褐地形纹理 | 全屏或半屏地图 |
| `cite` | `#8A8078` 极小 | 「据《大慈恩寺…》」「人物示意」 |

**字体**：主句宋/明衬线；脚注更小无装饰。  
**字号**：主句约 **5–7% H**；一屏常见 **8–16 字**（偶尔两行叙事）。  
**强调语法**：不是改色整词块，而是 **彩色下划线**（蓝=动机/数量，红=冲突动作）。

**阅读顺序**：左上主句 → 中/右纸偶或地图 → 右下账号水印 → 底栏出处。

## 5. KEEP / SWAP / 适合

**KEEP（来龙史剧底座核心）**：纸偶几何人、土褐夜色、左上短句、彩下划线、地图 HUD、出处脚注、示意声明。
