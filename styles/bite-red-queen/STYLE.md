公式/金句永远出现在 **gadget 状态差**（位移卡住、差距不变、舞台不变）被看懂之后。

## 2. KEEP · 语法

### 2.1 色板角色（语义色 · D3）

| 角色 | 用途 | 锚 |
|---|---|---|
| **近黑场** | 主底；可微网格/棋盘透视，少纹理 | `#0A0A0A`–`#121212` |
| **语义红** | 用力 / 陷阱 / **不变的位移或差距** / 章节标 / 关键词高亮 ≤2/屏 | `#E23B3B`–`#FF3B3B` |
| **ink 白** | 叙事主句、次要节点、非强调 HUD 值 | `#F5F5F5` / `#FFFFFF` |
| **muted** | 免责、次级标注 | `#6A6A6A`–`#8A8A8A` |
| **禁止** | 第三语义主色（勿再加金/蓝抢「不变/用力」职责） | — |

与近亲差异一句：`dianzi` 蓝结构·金惊奇；`moyou` 琥珀金主强调；**本底座红=相对努力陷阱/不变**，不是惊奇金。

### 2.2 字阶系统（密帧实测 · D2）

| 角色 | 证据帧 | 约字号@1080 | 字重 | 颜色 | 位置 |
|---|---|---|---|---|---|
| **kicker** | `04`/`03`/`07`/`08`/`12` · `II 军备竞赛` / `I 定律` / `IV 接力` / `V 另一条跑道` / `VI 方向` | ~28–36px | 600 | 语义红 | 左上 |
| **hero** | `01` 钩问 · `12` 金句两行 | ~72–96px | 800–900 | 白 + 红关键词 | 左上/中上 |
| **callout** | 红椭圆 pill（学历…）· 跑道标签 · HUD 数字 | ~28–44px | 600–800 | 红描边白字 / 红数字 | 图内 |
| **foot** | 底栏叙事一句；角标免责 | 叙事 ~40–52px；免责 ~16–20px | 800 / 400 | 白(+红词) / muted | 底中 / 左下 |

关键词高亮规则：每屏语义红强调 **≤2 处**（词或数字）；HUD 里「反讽值」（如位移 0.00）可用红，速度类次要值用白。

### 2.3 线稿 / 舞台语法

- 细红线几何：椭圆跑道、网格、虚线 `x=0`、星座连线、树高轴。  
- 无真脸、无实拍主舞台；剪影 / 节点 / 试管图标即可。  
- 主物件 **persist + morph**；禁止每句清空重画。

### 2.4 文字 ↔ gadget handoff（D5 前置）

| 拍型 | 谁主讲 |
|---|---|
| A · Text-lead | 钩问 / 金句；gadget 作衬底或单标记 |
| B · Gadget-lead | RunnerHUD / Track / Stairs / Tube 主舞台；字缩成 kicker+foot+callout |
| C · Dual irony | 高 SPEED vs 零 DISPLACEMENT；舞台不变 vs 力气↑ |

相邻两拍至少换一次主讲权；禁止连续三拍纯字墙。
