## 0. 一句话

问句钩（同天同学为何差距）→ 发条小狗寓言（小蓝问牌子价钱 vs 小金问「靠什么动」）→ 机制拆解（发条/齿轮/曲柄标注）→ 数据反直觉（好学生每题说「没看懂」8 次 vs 差生 1.1）→ 问题质量 > 数量 → 时间线对照 → 马太效应 → CTA「你是小蓝还是小金？下次先问为什么」。

## 1. Palette & typography

| Token | Approx | Use |
|---|---|---|
| `bg` | `#0A0908`–`#1A1410` | 深褐黑，中心暖光带 |
| `gold` | `#D4A84B` | **小金 / 快路径 / 好问题** |
| `blue` | `#7EB6D4` | **小蓝 / 慢路径 / 浅问题轮** |
| `ink` | `#F2EEE6` | 主文案 |
| `muted` | `#8A8580` | 背景「第 N 天」、弱标签 |
| `schematic` | `#5AD0E8` 虚线青 | 机构示意图轮廓 |

**字体**
- 主问句 / 结论：**衬线**
- 数据大数字：加粗衬线或等宽，**显著大于**说明文字
- 零件标签：中号衬线 + 小号说明行
- CTA 副行可用略细无衬线

**字号（%H）**
- 开场大问句：约 **7–9% H**（「他」金 / 「你」蓝）
- 叙事句：约 **5–6.5% H**
- 对比大数（1.1 / 8）：约 **10–14% H**
- 零件名：约 **4% H**；说明约 **2.5% H**
- CTA 主句：约 **8–10% H**
- **一屏字数**：钩子可到 20 字；机制屏标签多但主句仍 ≤16 字

**阅读顺序**
1. 顶栏问句/结论句（左或中）  
2. 左右/上下对照图形  
3. 大数字  
4. 角注文献

## 4. How it holds attention without VO

- **角色色编码**：扫一眼知「谁好谁差」  
- **寓言→抽象**：小狗零件映射学习原理  
- **大数冲击**：1.1 vs 8 不靠解说  
- **迁移打脸**：新年玩具小蓝重问、小金迁移  
- **结尾身份选择题**：自我代入 CTA  

无底栏字幕；偶有零件小标签属于图注，不是 VO 转录。

---

## 5. KEEP vs topic-specific

**KEEP**
- 双色角色对照语法  
- 问句钩 + 机制拆解标注 + 数据卡 + 马太/复利收束 + 身份 CTA  
- 金=有效路径，蓝=空转路径  

**SWAP**
- 寓言物件（发条狗可换成电路、菜谱、球拍…）  
- 具体实验引用  
- 时间跨度数字  

**适合选题**：学习方法、元认知、刻意练习、复利/马太、提问质量、迁移能力。
