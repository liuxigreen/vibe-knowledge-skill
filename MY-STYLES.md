# Make a style your own

Two ways: **change a library style**, or **start from a blank distill**. Confirmed personal styles live in **`~/vibe-my-styles/`** (outside the library) so updates never overwrite them.

Each personal style folder mirrors the library shape:

| File | Holds |
|---|---|
| `style.json` | slug, en, cn, based_on, line, line_cn |
| `STYLE.md` | invariants only (KEEP/BANNED/mode/type/props) |
| `style.yaml` | machine form |
| `CHANGES.md` | decisions vs base |
| `notes/DISTILL-GAP.md` | densest evidence |
| `poster.jpg` | optional contact / styleframe |

List every personal style in `~/vibe-my-styles/README.md`. Never write into this repo's `styles/` for a personal variant unless you are the library owner following [`MAINTAINING.md`](MAINTAINING.md).

Films using a personal style still follow [`AGENTS.md`](AGENTS.md) + Award gates.
