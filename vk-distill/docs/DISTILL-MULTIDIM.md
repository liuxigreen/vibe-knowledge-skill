## 1. 八维必锁（缺一维 = 未蒸馏）

### D1 · 论证骨架（Argument）
- 一句话静音能懂的路径：钩 → 机制演示 → 反直觉 → 日常落点 → 收。
- 理论锚点（作者/实验/概念名）+ **示意**边界。
- 撞车检查：与已做选题 theory-family 是否碰撞（见 PROGRESS-LADDER）。

### D2 · 字阶系统（Type ladder）≥4 级
从 densest 密帧实测，禁止臆造：

| 角色 | 字号@1080 | 字重 | 颜色角色 | 位置 |
|---|---|---|---|---|
| kicker | | | | |
| hero | | | | |
| callout / capsule | | | | |
| foot / HUD | | | | |

附：关键词高亮规则（烫金/对比色 ≤2/屏）。

### D3 · 色板语义（Palette roles）
- 主强调色职责（不是装饰）：指向什么（惊奇/重点/已播放…）。
- 结构色 / ink / muted / 禁止第三语义主色。
- 与同家族底座的差异一句。

### D4 · 3 秒动势清单（Motion）
每个论证拍写清 **谁在动**：
- persist 床/路径（不消失）
- morph / fill / playhead / stagger / path-walk
- 静帧死板或 card-swap = 本维 Fail

格式示例：`t+0.0 播放头右移 · t+1.2 金填充到 DROP · t+2.0 标注骑位点弹出`

### D5 · 图内展示（In-frame show）
按 `INFRAME-SHOW.md`：≥70% 论证挂在 gadget 状态变化；裁底栏 mute 仍懂。  
Gate 字段：`crop-bottom mute: pass|fail`

### D6 · 道具语法（Props / gadgets）
| 模板名 | 做什么 | persist+morph 规则 | 禁止 twin |
|---|---|---|---|
| | | | |

至少 1 个 **新** 道具/隐喻（N≥1）；禁止只换文案。

### D7 · 节奏与时长（Beat density）
- 钩 ≤3–4s；叙事拍典型 ≤4–6s；禁 ~20s 单行 dwell。
- 参考全长 vs 我们目标全片（5–15 min dense）如何加密拍而非拖慢。
- 文案吸睛句 / 开场钩子原文摘录（X/H 评分锚）。

### D8 · BANNED twin list（Distance）
陌生人指静帧能喊出原作 → D Fail。逐条写签名动作/构图/物件；允许发明槽位另表。



## 1b. Mode 证据句（硬门槛 · 嵌进八维叙事）

每条底座必须写满两句，缺一句 = Mode 未锁：

| 句 | 必填内容 |
|---|---|
| **听轨一句** | BGM 名/评论指认 / 「本机未听轨」诚实缺口；若已听：有无语音 formant |
| **密帧一句** | 脚本承载面：kinetic 屏上字 / 底栏字幕 / 口播字幕带 / 口型头像 — 以帧为准 |

不确定 → 锁 `silent_text_first`，禁止发明口播字幕带当正文。

## 1c. 知识锚可信度（硬门槛）

| 项 | 必填 |
|---|---|
| 出处 | 作者 · 年 · 概念/实验名（可核） |
| 示意边界 | 哪些数字/图是叙事示意，不是实测数据 |
| 易杠点 | 评论区可能被挑战的断言 + 我们的处理（脚注 / 弱化 / 不写） |
| 免责 | 源片 disclaimer 是否保留；我们成片是否需要「个人观点/示意」 |

知识锚空口号或把示意数字写成「科学定论」→ Award **K** Fail。
