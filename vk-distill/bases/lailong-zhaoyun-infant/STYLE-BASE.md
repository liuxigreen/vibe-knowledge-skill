## 1. Palette & typography（家族同玄奘，本集差异）

同 `lailong-xuanzang-passport` 土褐纸偶底。本集加强：

| Token | Use |
|---|---|
| `scroll_red` | 卷轴/姓名高亮（黄皓） |
| `book_beige` | 打开课本/出师表页 |
| `answer_gold` | 收束金句整行 |
| `mark_blue` | 「三十六年」等时长强调 |
| `mark_red` | 「亮不答」等戏剧落点 |

**字号**：叙事句 **5–7% H**；收束金句可到 **7–9% H** 且整行金色。  
**一屏字数**：多为短叙事；冲阵叹句可到 ~30 字（少见，拆行）。
