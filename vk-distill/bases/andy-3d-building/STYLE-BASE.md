## 0. 一句话
**一镜到底 60 秒**：桌上手绘草图 → CAD 施工图 → 图纸“落”到村子空地上 → 挖槽浇基础 → 一块块砌砖、三层往上长 → 封顶放鞭炮 → 水电 X 光 → 外墙门窗 → 夜里拆层看房间 → 秋冬除夕烟花 → 最后一张账单 → 推门进屋 → 回到桌上那张纸（循环结尾）。
叙事驱动有两条：**天数计数器**（第 4 天 → 第 180 天）和**季节牌**（秋 · 入住第一年 → 冬 · 初雪 → 除夕）。

## 2. 建筑怎么“长”出来（技术判读）
1. **离散阶段加逐元素显现**为主，不是一整栋用剖切面往上扫。砖墙明显是**一块块按顺序出现**（微距能看见新砖落位），砖数计数器实时增长，和实例数一致 → 推断 **InstancedMesh 加按序号控制 `mesh.count`**（或按实例 index 的 shader 阈值）。
2. **楼层整层生长**：墙 → 圈梁 → 楼板 → 脚手架跟着加高，每层重复一遍。脚手架是程序化管架（黄木板 + 灰管 + 绿安全网片）。
3. **局部剖切/阈值显现**用在浇筑上：基础板、楼板混凝土像“填充”一样铺开（像沿平面的 clip 或 scale 动画）。
4. **CAD → 场景的过场**：2D 线稿（白/浅蓝线框）保持屏幕位置不动，背景从深色 CAD 底换成土地，镜头再拉开 → 线稿变成地上的放线。**同一组线框几何先当 HUD 再当场景物体**，这是本片最聪明的一镜。
5. **X 光模式**：所有材质切到半透明白色加线框边，管线是发光线条（bloom），按路径长度生长。
6. **爆炸视图**：每层是一个 group，沿 y 轴拉开再合拢，加暖色点光，套 DOM 房间标签。
7. **机械**：低模挖掘机、搅拌车，动作简单（挖臂摆动、滚筒转），**没有塔吊**（农村自建房，靠脚手架）。
8. **季节/节日**靠粒子（落叶、雪、烟花 sprite 爆裂）、积雪盖板（屋顶加白色顶面）、灯光色温和道具（灯笼、春联）。

## 3. 镜头语言
- **一镜到底**：ffmpeg 场景检测（阈值 0.3）**0 个硬切**。转场全靠：镜头推拉加景深、昼夜换光、HUD 底换色（深色 CAD/夜紫做“章节呼吸”）。
- 一直在慢速环绕或摇臂运动，常在 3/4 俯视（约 35–50°）和微距贴墙之间切换；砖墙段用低机位横移加极浅景深。
- **强移轴/景深**（微缩模型感）：远处村子明显虚。⚠️ 用户偏好锐利 → 我们保留轻量 DOF，不能用 poc2 那种大移轴（`?tilt=0` 或缩小 kernel）。
- 背景是程序化村庄（白色和红砖小楼、树、道路），只做陪衬，不抢主体。

## 4. HUD 与文字层（无 VO，字幕即叙述）
- **左上章节标签**：橙色方块数字 `01` + 中文章节名（白，粗）+ 宽字距等宽英文（灰）`DRAWINGS`。下方可挂一行功能条：橙色等宽动词 `READ` / `STRAIGHTEN` + 白色中文说明。
- **右上天数**：`第 46 天`（数字橙色，特大）/ 等宽 `DAY 046 · 10:00` / 工序中文 `砌筑 · 二层` / 等宽英文小字。进入第一年后换成季节牌 `冬 · 初雪 WINTER · FIRST SNOW`、`除夕 NEW YEAR'S EVE`。
- **左下材料计数**：`砖 26,180 块 / 钢筋 1.5 吨 / 混凝土 52 方`，数字白色等宽粗体，标签下有极小英文 `BRICKS/REBAR/CONCRETE`。数字随工序跳动，**计数器本身就是信息**。
- **底部中字幕**：中文粗体白字，**一个短语高亮橙色**，下方一行**斜体衬线英文**半透明（如 *Every brick, laid in the real order.*）。一屏 4–18 字。
- **场景内标注**：小深色胶囊标签挂在构件上（「条形基础 宽1.2·深1.5m」「构造柱 ×16」「圈梁 · 层高 2.4」），以及 X 光模式左侧图例（电线管 300 米 / 冷水管 29 米）。
- 开场是**终端提示框**（`● Claude Code` + `> ` 光标打字），图纸阶段四角有坐标角标（405,54 / 1509,50…），营造“AI 在读图”的感觉。
- 总字幕约 12 句，平均每句停 4–5s；HUD 常驻，字幕和章节标签切换时淡入。

## 6. 时长与节奏
- 60.8s，6 章：图纸 10s · 基础 9s · 主体 11s · 封顶+水电+外装 5s · 入住/拆层 9s · 第一年+结算+回环 17s。
- 工期压缩：第 0→180 天大约在 10–44s 这 34s 里走完（平均约 5 天/秒，砌墙段放慢）。
- 情绪曲线：理性（图纸、数据）→ 劳作（砖）→ 高潮①封顶鞭炮 → 温情（亮灯、拆层）→ 高潮②除夕烟花 → 账单收束 → 回到纸（回味）。
- **开头 2 秒钩子**：终端打字「把这张草图，盖成一栋真房子」，一句话就把整片的承诺讲完。

## 7. 可复用要点（给我们的系列）
1. **“承诺句 + 一镜到底兑现”**：开头一句 prompt 式钩子，60 秒连续镜头兑现，不切镜。
2. **三层 HUD 分工**：左上是在哪一章，右上是第几天、在干什么，左下是累计了多少；字幕只负责情绪和重点。静音也看得懂。
3. **计数器 = 实例数**：砖数、管长跟着几何真实增长，数字和画面互相作证。
4. **同一几何跨层复用**：2D 线稿 → 地面放线；把这种“HUD 变成物体”当招牌转场。
5. **昼夜/X 光/爆炸视图当章节呼吸**，不用硬切。
6. **生命周期收尾**（季节、节日、账单、回到纸）让工程片有温度，适合抖音完播。
7. **英文小字副线**：斜体衬线英文和等宽英文标签显得“国际化、精致”，成本很低。
8. 不要照搬：原片的具体数字、Claude 代码行数自夸、湖南均价脚注。

## 8. 适配我们题材（不限房子）
- 「一座 XX 是怎么建起来的」：自建房、教学楼、土楼、四合院、窑洞、高铁站（要配塔吊）。
- 「一栋楼的一生」：建造 → 入住 → 老化 → 翻新/拆除（计数器换成年份）。
- 反向用法：「拆一栋楼」用同一套语法倒放。
