## 1. Palette & typography

| Token | Approx | Use |
|---|---|---|
| `bg` | `#050505`–`#0C0C10` | 近纯黑暗房，极淡颗粒 |
| `ink` | `#F5F2EA` | 主文案宋体白 |
| `accent` | `#D4A84B` / `#C9A227` | **唯一**点睛：关键词、光环、金词 |
| `ghost` | `#3A3A42` 低透明 | 背景弱引语、远景轮廓 |
| `line` | `#C8C8D0` 细线 | 剪影描边、几何弧 |
| `cite` | `#9A9AA5` 斜体小字 | 书名 / 年份脚注 |

**字体**
- 主文案 / 片名：**宋/明衬线**（高对比粗细）
- 英译角标：衬线小写/斜体（`The Halo Effect`）
- 数字与引文：同族更小
- **无 emoji**；无粗黑体大标题轰炸

**字号（相对帧高 H）**
- 片名左上：约 **4–5% H**
- 主句（一屏核心）：约 **6–8% H**，≤ 2–3 行
- 关键词金高亮：同字号，色改金
- 脚注/书名：约 **2.5–3.5% H**
- **一屏汉字量**：通常 **8–18 字**；金句卡可到 ~22 字，绝少挤满

**阅读顺序**
1. 左上固定片名（全程锚定）  
2. 主文案（左中或居中偏上）  
3. 图形隐喻（中/右）  
4. 右上作者水印「叁号暗房」  
5. 底部/中部脚注（若有）

## 2. Shot rhythm（≈162s）

| 段 | 约时 | 角色 |
|---|---|---|
| 冷开钩 · 剪影光环 | 0–8s | 「为什么喜欢一个人…美化一切？」金词「美化」 |
| 日常夸张例 | 8–28s | 明星头发丝 / 行为大条→你夸随性；道具杯倾金液 |
| 片名锚定 | ~16s 起 | 左上《晕轮效应》+ The Halo Effect 常驻 |
| 定义 | 30–50s | 月晕图解；「冰晶折射」 |
| 机制/实验 | 55–80s | 人群剪影看展；Nisbett & Wilson, 1977 |
| 文学升华 | 80–120s | 《追忆似水年华》双影；「消散的只是冰晶」 |
| 哲学收束 | 120–150s | 「情人眼里出西施」；尺度对比小人看大影 |
| CTA 反问 | 150–162s | 眼瞳里嵌人影+金虹膜；「是她，还是你眼里的…」 |

切镜偏慢：**约 4–7 镜/分**；单屏文案停留 **2.5–5s**；图形微动（粒子/光晕呼吸）维持静音注意力。

## 4. How it holds attention without VO

- **金词锚点**：每屏只点亮 1–4 个字，强迫扫读停顿  
- **隐喻连续**：光环 → 冰晶 → 消散，道具同族变形  
- **负空间**：≥50% 近黑空，字与形分离  
- **慢揭示**：末句淡入/模糊收（如 CTA 省略号）  
- **权威脚注**：年份/书名抬可信度，不抢主句  

字幕：**无**底部滚动字幕；所有字都是设计过的主视觉。

## 5. KEEP vs topic-specific

**KEEP（底座）**
- 纯黑暗房 + 单金点睛 + 宋体主字  
- Sticky 左上中英题  
- Halo / 剪影 / 负空间构图  
- 生活钩 → 定义 → 实验脚注 → 文学升华 → 反问 CTA  
- 一屏一事、金词 ≤ 一处高亮  

**SWAP（换题）**
- 具体隐喻道具（光环可换成滤镜、面具、染色玻璃等）  
- 引用文献与文学例子  
- 日常对照句对  

**适合选题**：认知偏差、情感投射、第一印象、刻板印象、审美偏见等「内观心理」题。
