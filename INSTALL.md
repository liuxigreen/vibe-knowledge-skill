# Install · 2026-11-01 lemo-like reshape

1. Clone or unzip so the root has `AGENTS.md`, `styles/`, `plugin/`, `docs/`, `assets/`.
2. Install skills from `plugin/skills/vibe-knowledge-film` and `plugin/skills/vibe-topic-pipeline`.
3. Set `$LIB` to this root (docs used to say `/workspace/vk-distill` — that tree is now this library).
4. Fonts: `assets/fonts/`. Silent BGM: `assets/bgm/we-never.mp3`.
5. Read `AGENTS.md` → pick a style in `styles/README.md` → follow `DIRECTOR.md`.

Legacy zip path `vk-distill/bases/` maps to `styles/<slug>/` (`STYLE-BASE.md` → `STYLE.md`, `style-base.yaml` → `style.yaml`).
