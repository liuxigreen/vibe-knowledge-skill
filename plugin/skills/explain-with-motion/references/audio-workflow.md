# 音轨研究与镜头表

先确认能否实际听辨音轨。可以提取音频或测量振幅，不意味着代理已经听到声音；无法听辨时将主观结论留空。

听审沿全时长进行，重点段重听并对照源画面：

- 配音：逐字稿、句起止、有效字/秒、句间停顿、重音、情绪。字速只在已校对稿与对齐时间成立时计算；不要由总时长猜测。
- 音乐：入退场、循环边界、段落转换、人声遮蔽。描述听到的性质；曲名、乐器、生成工具未知则不推断。
- 音效：听辨具体事件与起音范围，再检查视觉触发帧。混音峰值不能单独证明某种音效。
- 留白：区别人声停顿、仅留音乐、全混音静默。

镜头表增加 `voice_text, voice_start/end, stress, pause, music_state, sfx_event, audio_onset_range, visual_trigger_pts, timing_offset_range, evidence_type`。声音起点不清时保留范围，不把压缩振铃或包络峰当精确起音。

可测量全混音LUFS、真峰、响度范围及局部包络，注明算法、窗口、音轨和源时间。未经分离，不能拿整体响度当人声响度；不能从低静音比例推断连续讲话。短片LRA和不同长度材料的比较需保留限制。

制作先让配音说清信息，再为语义节点安排音乐变化和必要音效。验收依次检查：人声可懂、停顿给理解时间、强调位置对应信息、音画偏移符合设计、真峰和响度适合交付目标。不要为所有动作都添加提示音，也不要把来源不明的具体响度值设成通用平台规范。

本22条案例已有全混音测量和关键区间音频导出，尚无实际听审结论。这是研究缺口，不可借用视觉技法库填补。
