# 转场与状态节奏：补充连续帧

此前“软叠化·地图旅程”是研究标签，不能代替具体转场证据。本次另取两段全部实际源帧，实际查看8页联系表，共150帧：烽火[2,5)秒90帧，长安[5,7)秒60帧。24段连续证据合计29秒、870帧，仍不等于22条全片逐帧。下列精确位置来自源PTS，变化范围是联系表人工观察的近似定位，不是拟合的原始动画参数。

## 烽火：从地面场景到满幅地形

ID `7693231930334855918`，n60–149。2.000秒仍是烽台、远山、天空与火光；约2.133秒开始可见地表起伏覆盖旧场景；2.267–2.500秒之间满幅地形成为主体，火点保留下来并改变屏幕位置和尺度。没有先整屏黑场再建立新图，旧烽台和新地形在中间帧有混合可见关系。这个区间支持“柔和交接+亮点锚定”，不支持断言原作者采用了哪一种混合模式、相机矩阵或3D软件。

约2.667秒出现向右下的第二亮点，2.8秒后暖线逐渐连接；到4.9秒附近，路线抵达右下地点并出现长安标注。地貌有连续山脊与沟谷阴影；路线和火点在地表之上，正文固定于左上。观感由地形表面、明暗和地图范围变化共同提供，不能只复刻发光线。

可复用的制作次序：独立保留屏幕正文；将旧场景的火点身份映射为地图节点；过渡中保持它可追踪；地形成为主体后再推进路径并到达下一地点。过渡时长、位置和曲线在新作品中另定，不抄作原工程数值。需要真实地理的主题先核对路线；隐喻地图标示意。

## 长安：以离散状态收束，而非所有项目匀速变化

ID `7693771749486813678`，n150–209。5.000秒地图已在画面，计数731；5.2秒891、5.4秒971，约5.7秒达到1000。显示增量明显逐步收小，但不能仅由显示整数反推原曲线。城市亮点随状态逐渐退出，约5.7秒后范围环扩展；文字、数字、圈、城市灯点不是同一个透明度开关。

约6.0秒范围圈跨过城区边缘，6.1–6.4秒继续扩张后退到画外；6.567秒前后坊块边框重新变得清楚，说明“城市轮廓”和“灯点”应是可独立控制的解释层。不要为增加热闹而让所有灯点一直闪烁；高潮后允许暗下与停留。

候选实现把 `countProgress, lightState, boundaryVisibility, ringAge, textState` 分开，再由语义事件表调度。上述变量是制作设计，不是鉴定出原代码。
