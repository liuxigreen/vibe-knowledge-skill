# project.json最小格式

把每个元素的计划完整可见区间写出；淡入结束前的时长不计入阅读时间。时间单位秒，区间左闭右开。此格式用于新工程，不要求为22个研究样本伪造工程事件。

```json
{
  "duration": 10,
  "fps": 30,
  "shots": [{"id":"main", "t0":0, "t1":10}],
  "texts": [{"id":"title", "text":"一滴水的旅程", "t0":7.5, "fully_visible_t0":7.7, "t1":10, "role":"title"}],
  "events": [{"id":"water_arrives", "t":7}, {"id":"level_rises", "t":7.1, "requires":["water_arrives"]}]
}
```

`shots`应覆盖时间轴且无未声明的重叠。柔和交接可在后一个镜头写 `transition_in: true`，同时在导演方案记录交接锚点与层间动作；这个布尔值只声明重叠，不证明过渡合理。

文字 `role` 允许title/body/label/micro。默认读时启发式：中日韩文字4.5字/秒、其他非空白字符15字/秒，正文和标题再留0.5秒反应，标签和小注留0.25秒；所有字都检查，小注不会静默跳过。这是可调的项目检查起点，不是原片测得参数或普适认知标准。最终须在目标屏幕上验证；不够读时优先删字/延长，不提高阈值来掩盖问题。

`events[].requires`列需要先发生的事件ID；依赖缺失、循环、自依赖和先后倒置都失败。同秒事件可有意同步；检查器不推断实际接触帧。没有某类项目时显式给空数组，不等于视听检查通过。

运行结果：0=清单检查通过；1=检测到问题；2=输入或工具错误。返回0只表示这个清单的时间与文本启发式检查通过，不代表媒体、风格或声音通过。
