# 暗色古代叙事画面：观察与制作规格

## 使用边界

本规格供**明确选择暗色古代故事视觉**的制作者使用。题材发生在古代，不足以自动选择此风格；先确认观众需要跟随人物、地点和制度叙事，而不是看现代图表、写实电影或文物展陈。参考样本是《长安宵禁》`7693771749486813678` 与《唐朝烽火与平安火》`7693231930334855918`。下文“观察”仅描述本地源帧及案例记录；“制作选择”是便于复现的方案，不能当成原作者工程事实。不能保证任意生成模型仅凭文字达到像素级一致。要提高一致性，应复用同一套场景、人物、材质、字体、色板、相机和转场模板，并逐帧人工检查。

## 已观察到的视觉关系

- 《长安宵禁》是16:9暗夜场景，城门、坊市俯视图、室内烛火、街道和卷轴之间切换。主角与配角常是白色简化人形；人物通过姿势、位置、骑马、持火把和与建筑的关系表达身份。暖灯从局部照亮场景，深蓝黑与褐黑保留大面积暗部。白字叙述、蓝字引文或强调、红字禁令形成层级。城市俯视场景以屋坊的透视网格和逐区点亮说明制度影响。依据：完整案例与 `reviewed-seven/7693771749486813678-dense-04.jpg` 等源帧联系表。
- 《唐朝烽火与平安火》不仅是“古风地图背景+发光路径”。地形在地图段落占据**整个画框**，山脊、沟谷、坡面和暗部遮挡形成可感的体积；火点、地名和线路嵌在地形之上。开篇和中段的烽台也是有侧面、投影与地面接触的实体。暖金火光与冷暗地表构成注意力中心。上方文字清楚地分行，并以金色标出变化变量。依据：`group-a/.../complete/dense-page-01.jpg`、`dense-page-02.jpg`。源帧能证明呈现出的体积和遮挡，不能证明原片用了真实3D、高度图、法线贴图或具体渲染器。
- 两片都让场景承载解释：地形说明距离与传播，城市说明坊门和街道，人物说明遭遇。几乎所有亮点都与一个对象或事件绑定；不要把它们统称为粒子装饰。

## 16:9画面模板（制作选择）

1. 先画可辨的**环境实体**，再加文字和特效。地图镜头让有起伏的地表延伸到四边，主体地貌占画面约七成以上；只有大字叙述区域允许压暗。街景镜头让路面、建筑、山线或门楼占据完整空间，避免一条地平线、几个圆点悬在大片空黑中。
2. 分清三层深度：近景的树/土坡/墙角可局部遮挡主体；中景放人物、烽台、农具、院落；远景用山脊、屋顶轮廓与低对比天空。每层都有不同亮度和移动速率。地图用起伏坡面、脊线阴影、沟谷遮挡和火点投影建立空间，而不依赖等高线或发光描边充数。
3. 地表材质低饱和、粗粝、有大中小尺度变化：大形决定山谷与坡向，中尺度决定褶皱，小尺度只在近景可见。单一主光源给山体和物件侧面明暗，接触阴影把烽台、树、人物和房屋压在地面。亮部克制；火光/窗光有小范围暖色溢出，不能把整张地形洗成橙色。
4. 建议色彩角色：背景蓝黑/炭褐，地形暗棕灰，人物骨白，火与重要路径暖金，危险或否定暗朱红，引文或次级证据冷青蓝。颜色同时配文字和位置，不能单靠色相区分史实状态。
5. 故事场景的道具需有可见轮廓和体积：古代房屋应有屋檐、侧墙、门洞和投影；田地应有畦垄、土块、植物或工具；庭院应有墙面、树、月光落地。不要用无材质的矩形与细线代替整个场景。

## 人物与空间叙事（制作选择）

- 用统一的简化人物系统：圆或略扁的头、带袖口的躯干、独立上臂/前臂、可旋转的腿、必要时一块裙袍或宽袖形。正、侧、背三种朝向保持头身比例和衣色一致。角色轮廓在手机尺寸可认；人物与地面的接触阴影连续。
- 角色动作应由关节状态产生：走路至少有交替腿、轻微身体上下与手臂反向摆动；耕作有弯腰、手与农具接触、推/拉后的短暂恢复；对友人转身或抬手有清楚的准备和停顿。不要整个人形沿直线平移来代替行走，也不要让上肢漂浮、关节分离。
- 低光下人物可以保持简洁白色，但近景要让面向、袖形与相互距离说明关系。姿态、持物和站位比脸部细节更关键。

## 地图、相机和转场（制作选择）

- 地图里的路线必须服从地形：经过山口/谷地，随地表透视和镜头移动；地点标注锚定地理节点，屏幕叙述字固定在画框。先建立地点，再显示方向与行程状态。路径光是阅读线索，不宣称真实速度或实测路线。
- 地图旅行可用缓慢俯斜镜头前推/横移：近坡移动更快、远脊更慢；火点、建筑和标签随世界运动。保持一个可辨锚点，避免同时剧烈旋转、缩放和路径绘制。
- 从地图转到实地，建议让目标地点的光点或地形轮廓先占据注意中心，再以短暂柔和溶解显出同方向的道路、田地或院落；至少在过渡中保留一个形状、位置或光源连续。**这是推荐的制作手法**。现有案例笔记和2秒全片采样不足以确认参考片每一处转场确实采用何种精确溶解、遮罩和时长；逐帧核对前不要把“柔和溶解”写为原片事实。
- 每次转场只回答一个问题：我们到了哪里、时间如何变化、焦点从谁转到谁。相机运动不应与对象运动相互抵消或使地理方向颠倒。

## 文字与节奏（制作选择）

- 大字置于稳定的左上或上方暗区，保持宽边距；一行一个易懂分句，按语义断行。重点词只在叙述需要时换暖金/冷蓝/朱红。不要逐字跳字或让发光效果吞掉笔画。地名贴近地点；来源小字与叙述分层，手机尺寸仍需能辨认。
- 状态驱动而非平均分配动画：`地图地点已建立 → 路线推进 → 到达 → 场景动作 → 情绪停顿 → 下一场`。每个状态有清楚的进入、保持、退出；文字出现与对象变化有先后，给观众时间先看懂环境，再读结论。
- 小动作服务环境生命感：火焰轻微变化、灯光缓慢呼吸、月光或雾层小幅移动、角色衣袖余动。控制幅度和频率；静止段也允许真实停顿。避免全画面每秒都在漂移、闪烁。
- 声音若未听审，不写“参考片用了某种配乐/鼓点”。制作时可用稀疏环境声和少量事件声提示脚步、农具、夜风；让声音在转场处留呼吸。声音不能替代画面中需要看见的状态变化，也不要用音效峰值声称已复现声画同步。

## 苏轼黄州十秒试制的应用

这是依据《东坡八首》和《记承天寺夜游》**重组的意象叙事**，不是断言苏轼在同一天按此顺序行经这些地点。建议镜头状态：黄州地形与地名建立 → 路线/镜头带观众落向东坡 → 实体田垄中人物弯腰耕作 → 暗场或光源连续到月夜庭院 → 两位人物在月光中相遇并短暂停留。每个场景都要先给地形/场所体积，再加入动作与文字。地图段应有铺满画幅的起伏地表与实际遮挡；田地要看见土壤、畦垄和农具接触；庭院要看见树影、墙与月光落点。十秒只承载这一条视觉脉络，文句从两部文本中选择并准确标明来源，不编造同日行程。

## 验收

1. 静帧检查：关掉所有发光路线和文字后，仍能一眼认出地图地貌、田地和月夜院落；主体环境占画面主体，前中后景有遮挡、体积、接触阴影。若只剩线稿、圆点和大片空黑，退回场景制作。
2. 运动检查：逐帧看人物关节、脚/农具接触、标签锚定和地图投影；转场前后至少保留一个空间或光源对应点。停止运动任取三帧，地理位置与故事状态都能辨认。
3. 阅读检查：在目标手机显示尺寸，全文与来源可读；每句话语义断行；高亮词有明确含义；亮光不盖字。
4. 事实检查：原文准确，地图标“示意”时不暗示精确轨迹；重组镜头不被误解为单日纪实。记录哪些是源帧观察、哪些是本次制作选择，并保存所用模板与关键帧供后续复核。
