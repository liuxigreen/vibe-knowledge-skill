# 一滴水的旅程：专题示意工程

无旁白、无配乐、少量屏幕文字；10秒横屏。一个青蓝色视觉锚点先通过满幅起伏地形，经过概括的处理设施，再进入城市剖面管网，最终进入水龙头和杯中。

候选一是按流程并列图解，优点清楚、缺点易像流程图。候选二是跟随一个水流锚点跨尺度，能把远处来源变成身边日常；本例采用后者。地图交接与管网接近保留青蓝标记，两个转场用柔和混合而不是黑场。

0–3.2秒地形用于建立水源与处理位置，2.65–6.25秒城市剖面展示地表以下的连接，5.7–10秒室内近景以杯中水位变化作结果。重叠区是转场，不是额外时间。相机移动在地形和城市阶段展示纵深，室内用固定近景让水位变化可读。

地形与建筑为程序投影；室内为分层绘制。未完整演示混凝沉淀过滤消毒，也不宣称真实路线、时间或城市设施。小型处理设施仍主要依赖标签说明；材质、运镜和转换尚属概念样片，不算已达到原参考片质量。

本仓库版本将片尾标题提前到7.5秒显示，避免原试片约1.47秒的读时不足。流到杯中之后才开始升水位。项目清单列出全部绘制的文字项目；实际渲染时还需检查大小、位置和对比，清单检查不识别像素。
